# Unity Project

A simple Unity game project developed as part of a coursework/assignment.

## Project Overview 

The game is about picking two tiles and remembering if they are identical and
then if you are able to check two of them they stay on the screen, if no they close

## Features
- Win/lose conditions
- Restart functionality

## Built With
- Unity `2022.3 LTS`
- C#
- Visual Studio / VS Code
